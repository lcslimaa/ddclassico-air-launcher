# Contribuindo

[English](CONTRIBUTING.en.md)

Leia arquitetura, decisões e estado atual antes de alterar o bootstrap ou os controles. Use fixtures sintéticas nos testes. Nunca inclua sessões, cookies, HARs, SWFs, decompilações ou perfis em commits/issues. Faça testes primeiro para mudanças de comportamento, execute `npm test` e `npm run check:docs`, compile quando alterar ActionScript e registre o que precisa de confirmação manual.

Atualize os guias correspondentes em `docs/pt-BR` e `docs/en`; português é a referência editorial. Novas escolhas arquiteturais precisam de ADR com contexto, alternativas e consequências. Mudança de opinião deve substituir a decisão por outra referenciada, não reescrever silenciosamente o passado. Relatórios históricos ficam no arquivo.

Este projeto não escolheu licença de distribuição e não inclui recursos do jogo. Preparação para colaboração não concede direitos sobre materiais de terceiros.
