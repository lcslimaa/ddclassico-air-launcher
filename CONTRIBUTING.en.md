# Contributing

[Português](CONTRIBUTING.md)

Read architecture, decisions and status before changing bootstrap or controls. Use synthetic fixtures. Never commit or attach sessions, cookies, HARs, SWFs, decompiled code or profiles. Write tests first for behavior changes, run `npm test` and `npm run check:docs`, compile ActionScript changes and record outstanding manual verification.

Update corresponding guides under `docs/pt-BR` and `docs/en`; Portuguese is the editorial reference. Architectural choices need an ADR with context, alternatives and consequences. Supersede a decision through a linked new record rather than silently rewriting history. Historical reports stay in the archive.

No distribution license has been selected and game assets are excluded. Collaboration readiness grants no rights over third-party materials.
